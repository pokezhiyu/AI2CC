# 青柠蛇场系统架构

## 架构目标

在不引入远程服务和额外运行依赖的前提下，交付一个可测试、可独立部署、支持键盘与触屏的浏览器贪吃蛇，并让后继 Agent 能从 Workspace 和 Git 直接理解实现。

## 运行边界

- 当前 Workspace：需求、设计、开发、测试、Git 协作与本地预览。
- 正式生产环境：独立静态站点，由运维空间的部署说明承接，不在当前会话直接发布。
- 浏览器：运行游戏、渲染 Canvas、接收输入并保存本机最高分。
- 服务端：V1 不需要业务 API、数据库、账号或远程存储。

## 逻辑分层

```text
index.html
  ├─ 页面语义、游戏面板、状态区域、控制入口
  ├─ styles.css
  │    └─ Token、布局、响应式、控件状态、减少动态效果
  └─ game.js
       ├─ CanvasRenderer：棋盘、蛇身、果实、蛇头状态
       ├─ InputController：方向键、WASD、触屏、暂停、重开
       ├─ SessionController：计时、可见性暂停、界面状态
       ├─ LocalScoreStore：按模式保存最高分
       └─ game-core.js
            ├─ GameState：蛇身、方向、果实、分数、等级、状态
            ├─ RuleEngine：移动、穿墙、碰撞、成长、胜利
            └─ ModeConfig：轻松、经典、极速
```

## 模块职责

### `game-core.js`

- 使用纯函数表达核心规则，不访问 DOM、Canvas 或本地存储。
- 输入旧状态，返回新状态，便于确定性测试。
- 集中维护方向、模式、速度、得分、碰撞和果实生成规则。
- 允许注入随机函数，使果实生成可以稳定验证。

### `game.js`

- 连接 DOM 与核心规则。
- 根据当前状态调度下一游戏步。
- 将状态绘制到 Canvas，并同步得分、等级与文字状态。
- 接收键盘和触屏输入，转换成核心层方向命令。
- 使用浏览器本地存储保存各模式最高分。

### `index.html`

- 提供可理解的标题层级和明确的游戏操作。
- 为 Canvas、按钮、模式选择和状态区域提供可访问名称。
- 不承载业务规则。

### `styles.css`

- 维护深色云杉、青柠和琥珀视觉 Token。
- 在桌面提供游戏区与状态侧栏，在窄屏切换单列布局。
- 提供 hover、focus-visible、active、disabled 等状态。
- 遵循 `prefers-reduced-motion`。

## 状态模型

| 字段 | 含义 |
| --- | --- |
| `snake` | 从蛇头到蛇尾的网格坐标数组 |
| `direction` | 当前游戏步实际方向 |
| `pendingDirection` | 下一游戏步待应用方向 |
| `food` | 当前果实坐标；棋盘填满时为 `null` |
| `score` | 当前模式下本局分数 |
| `foodsEaten` | 已吃果实数量，用于等级计算 |
| `level` | 每五颗果实提升一级 |
| `status` | `idle`、`running`、`paused`、`gameover`、`won` |
| `lastEvent` | 最近一次规则事件，供界面和诊断使用 |

## 数据流

1. 用户输入被映射为方向或控制命令。
2. 控制器更新 `pendingDirection` 或游戏状态。
3. 定时器按当前等级调用 `advanceGame`。
4. 核心层返回不可变的新状态。
5. 渲染层根据状态重绘 Canvas，并更新可访问文字。
6. 得分超过当前模式最高分时写入浏览器本地存储。

## 关键约束

- 不允许方向直接反转。
- 果实不得生成在蛇身占用位置。
- 非成长步允许蛇头移动到本步即将离开的尾部位置。
- 经典和极速模式碰墙结束，轻松模式边界循环。
- 页面进入后台时自动暂停。
- V1 不将本地最高分上传到任何服务。

## 可扩展点

- 新模式：在 `MODES` 中增加配置，并在产品需求中定义规则。
- 新地图：核心状态增加障碍集合，并为生成、碰撞和渲染补充职责。
- 音效：在界面层监听规则事件，默认静音，不进入核心规则。
- 远程排行榜：必须先形成新的产品需求、隐私设计、后端架构和 ADR。

## 源码与知识同步

完整源代码快照位于 `技术空间/前端/源码备份/`，由 `npm run sync:code-backups` 从真实源文件生成。架构文档解释稳定边界，源码快照用于阅读，Git 保存历史；三者不能相互替代。
