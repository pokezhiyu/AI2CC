# 青柠蛇场产品愿景与路线图

## 产品概述

青柠蛇场是一款无需注册、打开即玩的浏览器贪吃蛇。产品保留经典规则，通过三种节奏、清晰反馈、键盘与触屏双输入，让用户在几分钟内获得完整、可重复的休闲游戏体验。

## 用户问题

- 许多轻量小游戏进入慢、广告多或必须登录，破坏即时游玩体验。
- 传统贪吃蛇常只适配键盘，在手机和平板上缺少可靠控制。
- 规则和状态反馈不清晰，用户难以理解失败原因或当前难度。
- 项目交付常只有代码，没有需求、设计、技术、测试和部署上下文，后续维护成本高。

## 目标用户

### 主要用户

- 希望在碎片时间快速放松的桌面与移动 Web 用户。
- 喜欢经典街机规则、不希望学习复杂机制的休闲玩家。

### 次要用户

- 用于 Web 入门教学、前端演示或 Canvas 学习的开发者与学生。
- 需要一个可独立部署、无后端依赖小游戏的内容运营者。

## 核心价值

1. **即开即玩**：无账号、无下载、无联网依赖。
2. **规则熟悉**：吃果实、增长、避障，进入成本低。
3. **多端可用**：键盘、WASD 与触屏方向键使用同一套规则。
4. **节奏可选**：轻松、经典、极速三种模式覆盖不同熟练度。
5. **可维护交付**：需求、设计、架构、代码、测试与运维资料按 Workspace 空间持续维护。

## 产品原则

- 首次进入只保留一个明确动作：开始游戏。
- 不用登录换取基础功能，不收集个人数据。
- 不以广告、弹窗或倒计时打断一局游戏。
- 失败必须说明原因，并提供立即重开的恢复动作。
- 移动端不依赖悬停，主要触控目标不小于 44 × 44 px。
- 动效服务于状态反馈，并遵循系统的减少动态效果设置。

## 当前产品范围

### V1 范围内

- 24 × 24 方格棋盘与经典蛇身移动。
- 果��随机生成、吃果实增长、计分和逐级加速。
- 轻松、经典、极速三种模式。
- 键盘方向键、WASD、空格暂停、R 重新开始。
- 移动端可见的触屏方向键。
- 当前分数、模式最高分、等级和状态提示。
- 本地最高分保存，不上传个人信息。
- 响应式布局和基础无障碍支持。

### V1 范围外

- 登录、云同步、排行榜与社交关系。
- 广告、内购、订阅或虚拟货币。
- 多人实时对战。
- 关卡编辑器和复杂地图系统。
- 正式生产部署与域名配置。

## 产品路线图

### V1：可玩闭环

目标是完成“进入 → 开始 → 操作 → 得分 → 暂停/失败 → 重开”的完整闭环，并形成可独立交付的静态 Web 应用。

### V1.1：体验增强

- 提供音效开关，默认关闭声音。
- 增加对局统计摘要，如本局时长与吃到的果实数。
- 优化手机横屏与窄屏布局。
- 根据真实体验反馈调整速度曲线和触控灵敏度。

### V2：内容扩展

- 增加障碍地图与每日挑战。
- 增加可切换的高对比主题。
- 在不引入账号的前提下提供本机历史记录。
- 如确需跨设备排行榜，再单独评估后端、隐私与反作弊成本。

## 成功标准

以下指标在上线前以真实测试数据补齐，不预设虚构数值：

- 用户能否在进入页面后独立开始第一局。
- 键盘和触屏主流程是否都能完成一局。
- 失败原因是否能够被理解。
- 重新开始是否无需刷新页面。
- 320 px 至桌面宽屏是否保持可操作。
- 页面是否在目标生产环境的性能预算内加载。

## 主要风险

| 风险 | 影响 | 产品应对 |
| --- | --- | --- |
| 触屏误操作 | 玩家非预期转向并快速失败 | 使用独立方向键、阻止页面滚动、禁止直接反向 |
| 速度曲线过快 | 新手挫败、留存下降 | 轻松模式穿墙，按吃到的果实逐级提速 |
| 规则扩张 | V1 交付延期 | V1 只做单人、单棋盘、三种速度模式 |
| 本地数据丢失 | 最高分重置 | 明确说明仅保存在当前浏览器，不承诺云同步 |
| 正式环境差异 | 本地可用但线上异常 | 运维空间单独维护构建、部署与回滚说明 |

## 决策边界

- 产品空间维护目标、需求、范围、优先级与验收标准。
- 设计空间维护流程、布局、视觉与组件行为。
- 技术空间维护架构、实现约束与技术决策。
- 测试空间维护验证计划、用例和最终验收记录。
- 运维空间维护环境、部署、发布与回滚流程。
